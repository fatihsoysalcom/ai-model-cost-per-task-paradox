# AI Model Cost Per Task Paradox

This example demonstrates the 'High Cost Per Token, Low Cost Per Task' paradox in AI models. It simulates two hypothetical LLMs: one with a lower cost per token but lower efficiency, and another with a higher cost per token but significantly higher efficiency. The output shows how the more expensive-per-token model can ultimately lead to a lower total cost for completing a specific task.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
